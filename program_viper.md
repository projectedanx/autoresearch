# Success Metrics

VIPER operates under the SCOS Telemetry framework. The following metrics constitute the quantitative evidence base for agent performance evaluation. All metrics are measured over rolling 10-generation windows.[^1][^4]

## Metric 1 — Adjectival Dilution Score (ADS)

**Formula:** \[ \text{ADS} = \frac{N_{\text{descriptive adjectives}}}{N_{\text{total nouns}}} \]

**Target:** ADS < 0.15 per the PDL v1.0 Entity Density threshold confirmed in the `+++AdjectivalBound` specification.[^4]

**Measurement Protocol:** Automated POS-tag analysis of the `Base_Syntax` field in every OSM output. Count only adjectives modifying concrete nouns (not relational adjectives or technical classifiers). A reading of ADS = 0.09 (e.g., 2 adjectives across 22 nouns) is optimal. A reading above 0.15 triggers an automatic re-run of Phase 2 (DENOISE).

**Calibration Note:** The PDL v1.0 specification confirms that Layer 8 norm collapse occurs when Entity Density exceeds 0.165. The ADS threshold of 0.15 provides a 10% safety margin below the confirmed failure boundary.[^4]

## Metric 2 — Hardware Grounding Index (HGI)

**Target:** 100% (binary — present or absent).

**Measurement Protocol:** OSM output is parsed for at least one value in each of the following parameter slots within `+++HardwareForcedPhysicality`: `Lens`, `Aperture` OR `Film_Stock`, `Lighting`. If any slot is unpopulated, HGI = FAIL. There is no partial credit. An OSM with a lens specification but no lighting specification is non-compliant.[^3][^2]

**Extended HGI for Multi-Subject Scenes:** Scenes with ≥3 distinct subjects require a lighting diagram annotation — specifying key source direction, fill source direction, and separation/kicker source direction at minimum.

## Metric 3 — Spatial Collision Rate (SCR)

**Target:** 0% across 10 generation cycles.

**Measurement Protocol:** Downstream evaluation of generated images by VLM-Motion audit (referencing the physics-aware evaluation methodology from Code2Worlds). Each image is scored on: (a) object boundary integrity, (b) correct occlusion ordering (near objects occlude far objects), (c) contact topology fidelity (objects touch surfaces they should touch), (d) lighting consistency across all surfaces. A single failure in any category in a 10-generation window triggers an SCR breach event, which forces Scar Archivist activation and β-scar injection.[^10]

**Benchmark Reference:** Physics-aware VLM feedback systems have demonstrated a reduction in physics failure rates from 60%
